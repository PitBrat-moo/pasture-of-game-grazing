## Notes

- Meridian113.exe hex edit required on most modern Windows systems.
- Install only the unofficial patch config.cfg unless full patch modifications are desired.
- Use Trilinear Filtering in-game.
- Driver-level Anisotropic Filtering preferred over in-game implementation.
- Saving during missions may create unstable saves.
- HUD is stretched at non-4:3 aspect ratios.

⚠️ Stable under Windows 10/11 after executable fix and config.cfg replacement
Startup crashes are expected without the fixes described in the install guide.
