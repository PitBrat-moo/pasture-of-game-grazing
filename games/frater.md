## Notes

- Frater Patch 1.4 recommended.
- Version 1.13 is the final free developer release and already includes the 1.4 update.
- dgVoodoo is required for stable DirectX rendering.
- Custom resolutions can be configured through the Windows Registry.
- Aspect ratios wider than 4:3 stretch the HUD.
- 3840×2160 has been tested successfully.
- Driver-level anisotropic filtering produces the best image quality.
- A crash near the Anger of the Earth cave requires a documented workaround.

⚠️ Stable under Windows 10/11 after dgVoodoo installation and resolution configuration

The Anger of the Earth cave crash is a long-standing game bug. A workaround is documented in the installation guide.
