Windows 10/11 Installation
------------------------------

Install game

Install the 1.3 patch

Install the NOCD fix
  Copy and replace Grom.exe from the NOCD archive into the ..\GROM\Run\bin\ folder.

Apply 4GB patch
  Run the patcher and select the game executable:
    ..\GROM\Run\bin\Grom.exe

To prevent the game from hanging at start:
  Delete or rename the intro movie.
    ..\GROM\Run\data\movie\intro.avi
    
Install dgVoodoo
  Copy these file to ..\GROM\Run\bin\
    dgvoodoo.conf
    dgvoodooCpl.xe
    MS\x86\D3D8.dll
    MS\x86\D3DImm.dll
    MS\x86\D3D8.dll
    MS\x86\DDraw.dll

Set the target framerate limit with RTSS.
(Optional) Apply shaders with Shaderglass.
Set the window size and position with SRWE.


DGVOODOO CONFIGURATION 
----------------------
Note: The game ignores dgVoodoo's windowed, scaling, and FPS settings.
      Use SRWE to adjust the game window size and position.
      Use RTSS to set the framerate limit.

• General  
  → Appearance: Windowed    
  → Scaling: Unspecified  
  → Keep window aspect ratio: Enabled
  → Capture mouse: Disabled  
  → Center app window: Disabled
• DirectX  
  → VRAM: 1024 MB (best for streaming)  
  → Filtering: App driven  
  → Mipmapping: App driven  
  → Resolution: Unforced
  → Application controlled fullscreen: Disabled  
  → Disable Alt‑Enter: Enabled  
  → Antialiasing (MSAA): App driven
  → Force vSync: Enabled  
  → Fast video memory access: Enabled  
  → dgVoodoo Watermark: Disabled  


GPU CONTROL PANEL SETTINGS
--------------------------

  Anisotropic Filtering: 16x
  Vertical Sync: On

NVIDIA:
  FXAA: Off (blurs textures)
  AA Gamma Correction: On
  AA Mode: Override any application setting
  AA Setting: 8x
  AA Transparency: 4x-8x
  MFAA: Off
  Anisotropic Sample Optimization: Off
  Negative LOD Bias: Clamp
  Texture Filtering Quality: High Quality
  Texture Filtering Trilinear Optimization: Off


RTSS
----
Note: 
   • Set framerate limit for improved stability or when using frame generation.
   • A 237 FPS cap is recommended for stability and to maintain consistent frametimes.
   • Adjust the framerate limit for the target display; use 60 for compatibility.
   
Add Grom.exe to RTSS.
Set Framerate limit: 237 FPS


SRWE
----
Note:
  • Use SRWE to set the size and position of the game window.
  • If using Shaderglass, apply SRWE to both the Grom and Shaderglass windows.
  
To center the 4x3 game window at 2160p and hide the top and bottom borders:
  Select running Application: Grom (Grom.exe)
  Width: 2896  
  Height: 2199
  Y: -31
  Align Window: H.Center


SHADERGLASS CONFIGURATION (OPTIONAL)
------------------------------------
• Output → Mode → Glass
• Output → Window → Click-through
• Input → Pixel Size → x1
• Shader → Import custom → grom-shader-authentic-enhanced.slangp
• Hide Menu (Shortcut key 'm')
 
  
LOSSLESS SCALING (OPTIONAL) 
---------------------------  
Note:  
  • The game already runs at very high framerates on modern hardware.
  • Lossless Scaling Frame Generation is optional and generally provides little benefit compared to native rendering.
  • Use RTSS to cap the framerate for frame generation.  

Use RTSS to cap framerate:
  • 237 FPS for native rendering
  • 144 FPS when using frame generation
  
• Frame Generations Type: LSFG 3.1  
• Mode: Fixed  
• Multiplier (base cap 144 FPS):  
     → 1.8 x 144 FPS (240 Hz @ ~231 FPS)
     → 1.9 x 120 FPS
     → 2.9 x 80 FPS
• Flow Scale: 20-30%  
• Performance: ON  
• Capture API: WGC  
• Queue target: 0 (1 for compatibility)  
• Clip cursor: Off (optional)  
• Adjust cursor speed: Off (optional)  
• Scaling Type: Sharp Bilinear  
• Rendering Sync Mode: Default  
• Max frame latency: 1  
• G‑Sync support: ON

STARTUP ROUTINE
>><------------------<<>
• Select Sound Playback Device
• (Optional) Attach Controller  
• Launch RTSS
• Launch SRWE
• Launch Grom  
• SRWE → Select Grom → set size/position 
• (Optional) Launch Shaderglass
             SRWE → Select Shaderglass → set size/position
             Shaderglass → x1 → Shader → Glass → Click-Through → Hide Menu
             Alt+Tab to the Grom window
• Play
