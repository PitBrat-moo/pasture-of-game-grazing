Windows 10/11 Installation
------------------------------

Install game

Hex Edit Meridian113.exe to prevent startup crashes:
  - Open Meridian113.exe in a hex editor like HxD.
  - Look for line 000001d0
  - Replace "80 F0 FA 02" (US STEAM) or "00 00 40 00" (COMMUNITY PATCH)
      with "00 00 30 00"

Edit data/config.cfg to prevent crashes and graphical issues:
  - Copy and replace the config.cfg file from the unoficial patch into the \HARD TRUCK APOCALYPSE RISE OF CLANS\data folder.

Set custom resolution:
  - Edit config.cfg
      r_desiredHeight="2160"
      r_desiredWidth="2880"
      r_fullScreen="false"
      r_height="2160"
      r_width="2880"

IN-GAME SETTINGS
----------------

Set graphics options to HIGH.
Set texture filtering to TRILINEAR.
  Anisotropic filtering causes graphical issues.

Instead, force anisotropic filtering in the GPU control panel.


GPU CONTROL PANEL SETTINGS
--------------------------

Any GPU:
  Anisotropic Filtering: 16x
  Vertical Sync: On

NVIDIA:
  FXAA: Off (blurs textures)
  AA Gamma Correction: On
  AA Mode: Override any application setting
  AA Setting: 8x
  AA Transparency: 8x
  MFAA: Off
  Anisotropic Sample Optimization: Off
  Negative LOD Bias: Clamp
  Texture Filtering Quality: High Quality
  Texture Filtering Trilinear Optimization: Off


RTSS
----

Note: 
   • Set framerate limit for improved stability or when using frame generation.
   • A 237 FPS cap is recommended when using a 240 Hz display to maintain consistent frametimes and VRR operation.

Add Meridian113.exe to RTSS.
Set Framerate limit.

Recommended:
  Framerate limit: 237 FPS

Optional (Lossless Scaling Frame Generation):
  Framerate limit: 144 FPS

  
SRWE
----

Use SRWE to set the size and position of the game window.
To center the game window at 2160p and hide the top and bottom borders:
  Select running Application: Hard Truck Apocalypse: Rise of Clans
  Width: 2896  
  Height: 2199
  Y: -31
  Align Window: H.Center

  • 237 FPS for native rendering

PATCHES / MODS
--------------

  https://github.com/JoomerOffical/EM-PatchOfMeridian

The full patch modifies gameplay mechanics and changes the language to Russian.

The unofficial config.cfg fixes:
  • Startup crashes
  • Screen blackouts
  • Blur effects triggered by damage
  • Miscellaneous rendering issues
  
Installing only the config.cfg from the unofficial patch is recommended.
  Copy and overwrite config.cfg from the patch into the data folder inside the game folder.


TWEAKS & FIXES
--------------

Fix for the "Unhandled exception errors" at startup:
  - Use a hex editor like HxD to edit the game executable.
    1. Browse to the game folder. (SteamLibrary > steamapps > common > HARD TRUCK APOCALYPSE RISE OF CLANS)
    2. Open Meridian113.exe with a hex editor. 
    3. Find the line 000001d0
    4. Replace "80 F0 FA 02" (US STEAM) or "00 00 40 00" (COMMUNITY PATCH) with "00 00 30 00"
    5. Save the modified executable.

Fix for crashing at startup and graphical issues:
  - In config.cfg (inside the data folder) change 
      autoPlayVideo="true" to autoPlayVideo="false" 
      r_compressedTextures="1" to r_compressedTextures="0"
      r_graphicalStats_MemAlloc="no" to r_graphicalStats_MemAlloc="yes"
      shaderMacro0="MIN_MAG_FILTER Anisotropic" to shaderMacro0="MIN_MAG_FILTER Linear" 

Fix for game crashing:
  - Start the game.
  - Open Task Manager.
  - Right-click the Meridian113 entry.
  - Select and set priority to HIGH.
  - Select and set affinity to a single CPU (CPU 2).

Fix to prevent crash at startup:
Note: This method is preserved for historical purposes; prefer the hex edit method.
  - In Steam go to properties of the game. Under 'Launch Options' add:
       cmd /c "set OPENSSL_ia32cap=:~0x20000000 && %command%"

Low FPS after loading a save:
  - Change the in-game graphics settings from the current to the minimum and back several times in the game menu, or reboot.


KNOWN ISSUES
------------

Crashing when loading saves:
  - Do not save the game during missions, the game may crash when loading. Try to save before missions, but be aware that saving can spawn a pack of bandits.

Bug on mission with tank and city defender:
  - Destroying all of the robots at the start of the mission creates a soft-lock. 
    The mission will not register as complete and new robots will not spawn.
    Fix: after spawning in the tank, wait until the robots come closer to the city (they can't destroy it) before destroying all of the little robots. Wait before destroying the big robots.

Screen Darkening / Stuck Fade Bug
If the screen remains dark or becomes stuck in a fade effect:
  - Restart the game first.
  - If that doesn't help, set graphics to Low.
  - Play past the location or event where the darkening occurs.
  - Create a new save after moving beyond the bugged point.
  - Load a save from before the darkening occurred.
  - Then load the new save created after the bugged section.
  - Restore graphics to Medium or High. Select Trilinear Filtering; Anisotropic is broken.

The HUD is stretched in aspect ratios other than 4x3; prefer 4x3 aspect ratio for stability.
