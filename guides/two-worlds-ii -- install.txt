Two Worlds II 
=====================  

A clean, stable setup guide for Two Worlds II on modern Windows systems, including fixes, configuration, and optional enhancements.

Focus: DX10 engine behavior, modern shader compatibility, and stable frame timing.

))(~~~~~~~~~~(()
INSTALLATION
(()~~~~~~~~~~))(

This guide documents the DX10 version of Two Worlds II (TwoWorlds2_DX10.exe).  
The DX9 executable behaves similarly, but some fixes (ReShade, window mode, CPU affinity) apply specifically to DX10.

Windows 10/11 Installation
------------------------------

Install game
   
Use RTSS to set the framerate limit to 100  

IN‑GAME SETTINGS  
----------------
Note: Disable HDR via AutoexecGame2.con
  
Graphics  
   • Window Mode: Off (unless using Lossless Scaling)
   • Anti-Aliasing Mode: 4x
   • Anti-Aliasing Samples: 1 sample
   • Detail Level: 3
   • Ambient Shadows: 10
   • Motion Blur Level: 0
   • Bloom Level: 0
   • DOF scale: 7
   • Anisotropy Level: 16
   • Draw Distance: 10
   • Grass Draw Distance: 10
   • Shadows: On
   • Vsync: Off
   • HD Video: On
   • Use safe area in interface: Off
   
Physics
   • Hardware Physic: On
   • Physic Detail Level: High

   
Configure AutoexecGame2.con  
--------------------------  
Notes:  
   • The game does not automatically generate a configuration file  
   • These commands also work from inside the game console  
   • FOV: 60 for 16x9 ; 80 for 32x9
     
Navigate to the game’s root folder (same level as TwoWorlds2_DX10.exe).  
If it doesn't already exist, create a folder named “Parameters”  
Inside Parameters, create a text file named “AutoexecGame2.con”  
Open AutoexecGame2.con in a text editor, add one of the following blocks, and save  


Beauty settings (may cause crashes if The Shattered Embrace DLC is installed) 
══════AutoexecGame2.con══════════ 
engine.fov 60
engine.hdr 0
graph.setfastrunspecialefx 0
sound.voicevolume 1.5
loadlevelmargin 1500
unloadlevelmargin 2000
interface.XInputEnable 0
══════End AutoexecGame2.con══════ 


Power settings (will cause crashes) 
══════AutoexecGame2.con══════════ 
engine.fov 80
engine.hdr 0
graph.setfastrunspecialefx 0
sound.voicevolume 2
loadlevelmargin 3000
unloadlevelmargin 4000
interface.XInputEnable 0
══════End AutoexecGame2.con══════ 


Stability settings (safe) 
══════AutoexecGame2.con══════════ 
engine.fov 60
engine.hdr 0
graph.setfastrunspecialefx 0
sound.voicevolume 1.5
interface.XInputEnable 0
══════End AutoexecGame2.con══════ 


RTSS   
-------
Framerate limit: 100 FPS
Scanline sync: 0 (OFF)


LOSSLESS SCALING  
----------------  
Notes:  
   • Use RTSS to cap framerate to 100 for frame generation  
   • Requires Window Mode  
     → Launch game → Settings → Graphics → Window Mode: On  

Settings:
• Frame Generations Type: LSFG 3.1  
• Mode: Fixed  
• Multiplier (base cap 100 FPS):  
     → 2.35  (100 Hz @ ~236 FPS)  
     → 2.4  (100 Hz @ ~240 FPS)  
• Flow Scale: 25-30%   
• Performance: ON   
• Capture API: DXGI (WGC for compatibility)  
• Queue target: 0 (1 for compatibility)  
• Clip cursor: Off (optional)  
• Adjust cursor speed: Off (optional)  
• Scaling Type: Sharp Bilinear  
• Rendering Sync Mode: Default  
• Max frame latency: 2  
• G‑Sync support: ON  

For smoother motion:
• Flow Scale: 20%   
• Performance: OFF    
• Max frame latency: 1  


RESHADE  
-------  
Note: Use ReShade 5.8.0 for best compatibility.
      Newer versions cause the game to freeze on the first splash screen and close.
      Only install the default ReShade + SweetFX package. Do not install qUINT, prod80, or depth‑based effects. 

Rendering API: DirectX 10/11
Custom Preset: two-worlds-2-shader-authentic-enhanced.ini
Effect Packages: Standard effects, SweetFX by CeeJay.dk

TWEAKS & FIXES  
--------------  
Crash at start with the HD version on Steam
   In the Two Worlds 2 game folder, go to -> Install -> PhysX, then run "PhysX_10.01.29_9.10.0129_SystemSoftware.exe" to install necessary files.

Crash at start with the Shattered Embrace DLC installed, even after PhysX (Steam_api.dll error).  
   Replace Steam_api.dll with a working version from another game:
      • Legend of Grimrock
      • Skyrim
      • Mount and Blade
      • Many other older titles
   Copy the working DLL into the game folder and replace the old file.
   This is the only way to make the Shattered Embrace DLC playable.

Or

   Uninstall the Shattered Embrace DLC:
      Go to the Two Worlds 2 Steam Library page.
      The DLC tab is on the right side of the page, below friends who play, additional content, achievements, notes and trading cards. Choose Manage My DLC for the option to uninstall/install the Shattered Embrace DLC.

High view distance has an LOD bug in v2.0+.
   It's noticeable on the mountains in the Savannah and near the ocean. 
   Increasing loadlevelmargin/unloadlevelmargin fixes it, but may cause crashes if The Shattered Embrace DLC is installed.
   For the fix, configure AutoexecGame2.con with the beauty settings. 
   If crashes occur during teleports or in The Shattered Embrace DLC, use the stability settings.

The Grace engine struggles to maintain frame pacing at high fps or in ultrawide aspect ratios.
   Cap frame rate to ≤ 100.  
   Use aspect ratio 4:3 or 16:9.  
   
Voice audio is too quiet
   Increasing sound.voicevolume improves gain for dialogue. Volume can safely go up to 2.
      For the fix, configure AutoexecGame2.con.
          
Mouse input is unusable
   Having a controller attached can make mouse input unusable in the game.
   Unplug the controller or disable interface.XInputEnable and restart the game.
   For the fix, configure AutoexecGame2.con. 

Stuttering Fix  
   The DX10 version of Two Worlds II may stutter on modern CPUs because the Grace engine does not scale cleanly across many logical processors. Limiting the game to four physical cores restores stable frame pacing.

   Fix:
      Alt‑Tab → Task Manager → Details.
      Right‑click TwoWorlds2_DX10.exe → Set affinity.
      Select only logical processors: 0, 2, 4, 6.
      (These correspond to four physical cores on typical CPUs.)
   This prevents the engine from running on SMT/virtual cores, which cause irregular frame pacing.

Enable/Disable intro videos  
   Go to <path-to-game>\Video.
   Delete or rename intro1.wmv, intro1.ogg, intro3.wmv, intro3.ogg, intro5.wmv, and intro5.ogg.    
    
Restore missing resolutions
   Screen resolutions disappear from the graphics options in-game.
   Delete Height and Width in the game's registry key.
   Registry:
      Computer\HKEY_CURRENT_USER\Software\Reality Pump\TwoWorlds2\Graphics\

   Or 
   
   Set Height and Width to the desired values in the registry.
   Common Resolutions:
      Height = 0x5A0 = 1440
      Height = 0x870 = 2160
      Width = 0xF00 = 3840
      Width = 0x13B0 = 5040
      Width = 0x1400 = 5120
      Width = 0x1680 = 5760
      Width = 0x1E00 = 7680

Lossless Scaling mouse input stuck in original window
   Lossless Scaling may hook the wrong window after the first launch of the game.
   This causes the mouse pointer to remain locked to the original game window instead of the LS fullscreen window.
   
   Fix (do not disable Lossless Scaling):
      Alt‑Tab out of the game.
      Click once on the desktop.
      Click back on the game window.
      Lossless Scaling will return to fullscreen with correct mouse input.

KNOWN ISSUES   
------------  
Depth buffer is inaccessible; many ReShade effects will not work.

HDR is broken in the engine; keep engine.hdr 0.

EAX audio may cause crashes when used with virtual‑surround headsets; disable EAX in the game’s audio settings.
