Windows 10/11 Installation
------------------------------

Install game

Install the Community Remaster (TESTED)
   Requires ComMod mod manager.
   On Steam, right-click on the game > Properties > Set Language to "Russian". The game will then update.
   From the release page, download the latest zip folder.
   Launch the ComMod mod manager, and select the path to the game. If you own the game on Steam, the mod manager may automatically find it.
   Select a folder where your mods will be kept. This will create two folders at the designated location : "mods" and "logs_commod"
   Put the downloaded zip file containing the Community Patch in the newly created "mods" folder.
   In ComMod mod manager, click on the "Local Mods" page, then extract the mod.
   In the "Local Mods" page of ComMod, click on "Install" for the mod you want. A new page will open up, allowing you to choose if you want the Community Remaster or only the Community Patch, and the language you wish to have. Make sure to pick the English version if you want to play in English.
   After pressing "Yes" to confirm your choices, you will have the option to deselect optional HD models and textures, and revamped soundtrack. Choose what you want, and press "Yes". The installation will begin, and once done you will have a screen confirming that the installation process is done, with a list of changes made.

RTSS
----
Note: 
   • Set framerate limit for improved stability or when using frame generation.
   • A 60 FPS cap is recommended for stability and to maintain consistent frametimes.

Add hta.exe to RTSS.
Set Framerate limit: 60 FPS
